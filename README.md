# Crypto News

Agente de noticias cripto con análisis vía Claude y alertas a Discord, versiones v1–v3.

Parte de la flota de bots de trading automatizado (Python + ccxt, API de Bitget).

## Configuración

1. Copia `config.env.example` a `config.env`.
2. Completa tus claves (Bitget, Telegram, etc.). `config.env` está en `.gitignore` y nunca debe subirse.

> Las credenciales de este repositorio fueron reemplazadas por placeholders antes de publicar.
